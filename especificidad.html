Especificidad en CSS

¿Qué es?

La especificidad es un conjunto de reglas que utiliza CSS para determinar qué estilo tiene mayor prioridad cuando varios selectores intentan modificar el mismo elemento HTML. Es decir, permite decidir qué regla se aplica cuando existen diferentes estilos para un mismo elemento.

¿Para qué sirve?

Sirve para establecer qué regla de CSS tiene mayor prioridad. Esto permite evitar conflictos entre estilos y controlar cómo se visualizan los elementos de una página web.

¿Cómo funciona?

Cada selector tiene un nivel de especificidad. Cuando varias reglas CSS afectan al mismo elemento, el navegador compara su prioridad y aplica la regla correspondiente. En general, los selectores ID tienen más especificidad que las clases, y las clases tienen más que los selectores de elementos.

Ejemplo práctico

Si un mismo párrafo tiene un estilo definido por una clase y también por un ID, normalmente se aplicará el estilo del ID, porque tiene mayor especificidad.

#titulo { color: blue; }
.titulo { color: red; }

En este caso, el texto será azul porque el selector ID tiene mayor especificidad que el selector de clase.

Importancia de la especificidad

Conocer la especificidad permite escribir código CSS más organizado, solucionar conflictos entre estilos y tener un mayor control sobre el diseño de una página web.
